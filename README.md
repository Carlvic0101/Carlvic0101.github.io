# CarlLiu Portfolio

React + Vite personal site, hosted on GitHub Pages from the `docs/` folder.

## Local

```bash
npm install
npm run dev
```

## Deploy (GitHub Pages → `/docs`)

```bash
npm run build
git add docs
git commit -m "build: update GitHub Pages docs"
git push
```

Then in the repo: **Settings → Pages → Build and deployment**

- Source: **Deploy from a branch**
- Branch: `main`
- Folder: **/docs**

Site URL: https://carlvic0101.github.io/
